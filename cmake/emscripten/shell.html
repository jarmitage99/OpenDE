About

OpenDE runs UnrealScript bytecode from the shipped packages. This page is the same engine compiled to WebAssembly with Emscripten, using WebGL 2. It runs the shareware Deus Ex demo

Report any issues on the repo: github.com/jarmitage99/OpenDE

Controls

WASD to move, LMB to fire, RMB to use. F1 opens the inventory and ESC the main menu.

Settings and saved games are kept in browser storage.
