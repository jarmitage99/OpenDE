OpenDE

An open-source reimplementation of the Deus Ex engine, running the shareware demo in your browser.

During play, click the game to capture the mouse.

About

OpenDE runs the original game's UnrealScript bytecode from the shipped packages on a new C++ engine. This page is the same engine compiled to WebAssembly with Emscripten, drawing with WebGL 2. It plays the Deus Ex demo (version 1002f), which includes the training mission, Liberty Island and UNATCO headquarters.

Source code, build instructions and the issue tracker: github.com/jarmitage99/OpenDE

Controls

W A S D to move, mouse to look, left click to fire, right click to use. F1 opens the inventory and Escape the main menu. Keypad + quick saves and keypad / quick loads. In fullscreen, Escape returns to this page.

Settings and saved games are kept in this browser's storage.
